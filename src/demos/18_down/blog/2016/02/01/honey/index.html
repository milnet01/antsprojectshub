1 February 2016 Poetry

Honey

Honey if I can be honest
I dont understand a fucking thing
You opened up the floodgates
The raging waters destroyed everything

After all has been said and done
Is there any point to mention
The last thing I wanted was to lose you
But I did despite my best intention

I been talking to myself for days
I been dying in so many different ways
This hell is where I find myself
And it seems this hell is where I'll stay

I'm trying so hard to be courageous
But all I feel is contagious
I'm lost drifting sea
Just who the fuck will save us?
