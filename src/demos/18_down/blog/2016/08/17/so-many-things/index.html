17 August 2016 Poetry

So many things

There are so many things

That I deeply regret

I will try to forgive

But I know I'll never forget

I have begged for mercy

For all the things I've done

I pray for redemption

But all I've loved is gone

Wrap the days around me

Like a corpse covered with a sheet

Let me not wander the lonely streets

Find me so I can know some peace
