23 June 2014 Poetry

23 June 2014

I've been begging for mercy
For so very long
I've been pleading with the universe
But love is still gone
I have all the money in the world
All the time I can spare
I have so many things
And I just don't seem to care
I don't give a shit
if anyone thinks it's lame
This is my life
Not some stupid game
Where are my answers
I'm tired of questions that don't end
I'm not afraid of this pain
And I won't pretend
I won't smile
When nothing makes sense
Keep your promises
I don't need the pretense
I've heard it so many times
I've heard it all before
Some uplifting tripe
And I'm not listening anymore
