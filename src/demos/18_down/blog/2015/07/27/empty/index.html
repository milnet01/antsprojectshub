27 July 2015 Poetry

Empty

I don't need to be happy
Just don't want to feel so empty
All the smiles are so complicated

I don't need all the money
I don't want you to pity me
Besides it's all overrated

The angels and devils
They all know where I lie
Instead of hoping,
I just want to die

I been praying for so long
Been asking what I been doing wrong
I just got all these memories
Been listening to the same old song

I say all the same things
Repeating the same routine
I'd so love to be in love
And somehow now that feels obscene
